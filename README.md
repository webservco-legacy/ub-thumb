# ub Thumb

ub Thumb 1.0.071213 (2007): a PHP script that makes thumbnails with GD on the fly and keeps the aspect ratio. A historical archive, kept read-only: the PHP code of its time: not safe to deploy today, kept for its history.

## How it was built

There was no version control then: in 2026 I turned the archived files into a commit, with their date kept. The last
commit before this README sets LF line endings and indents with spaces.
